About Me

Welcome to my final website.

My name is Duy Nguyen, and I am a student at Dallas College. I am studying Computer Information Technology with a focus on web development. I enjoy learning how websites are built and how different parts of a page work together.

I am still growing as a developer, but I believe every assignment helps me improve. This website shows my learning progress and the web development skills I practiced during this class.

Skills and Knowledge Learned

In this class, I learned how to build web pages using HTML, CSS, JavaScript, and jQuery. I practiced creating structured pages, styling layouts, validating forms, handling events, using animations, and making pages more interactive.

  • Creating semantic HTML page structure
  • Using external CSS style sheets
  • Building responsive and user-friendly layouts
  • Writing JavaScript custom functions
  • Using jQuery selectors, events, and effects
  • Creating image galleries and interactive pages
  • Validating forms with JavaScript and jQuery

Technologies, Techniques, and Methods Used

Throughout this course, I used several web development technologies and methods to complete my assignments. These included HTML5, CSS3, JavaScript, jQuery, browser testing, validation tools, and version control with GitHub.

I also learned the importance of clean code, readable structure, accessible navigation, consistent styling, and testing my pages in different browsers and screen sizes.

Professional Goals

My professional goal is to become a front-end web developer. This class helps me move closer to that goal by giving me practical experience with real web development tools and techniques.

The skills I learned in this course will help me build cleaner, more responsive, and more interactive websites. I want to keep practicing and continue improving step by step.
